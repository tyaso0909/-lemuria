# 夢の境界線

忘れられた夢から生まれたナイトメアが、灯台「追憶の灯」へ押し寄せてくる。
防衛人形となって夢の住人を召喚し、100ウェーブ先まで灯を守り抜く、2D横視点・1レーンのカード召喚型ウェーブ防衛ゲームです。

ブラウザだけで動きます（PC・スマートフォン横画面）。

## 遊び方

- 画面下の5枚のカードをタップ（PCは数字キー 1〜5）して夢の住人を召喚します。召喚にはエネルギーを使い、エネルギーは時間で回復します。
- 住人は自動で前に出て戦います。召喚のタイミングとエネルギーの配分がすべてです。
- 10ウェーブごとにボスが現れます。ボスは出撃ごとに候補の中から抽選で、第100ウェーブには最後のボスが待っています。
- 階層を突破するごとに「灯の祝福」を3つから1つ選べます（その出撃の間だけ有効）。
- 戦闘で得た夢の結晶で、能力ガチャと交換所（新しい住人）を使えます。進行はブラウザに保存されます。

| 操作 | PC | スマートフォン |
|---|---|---|
| 召喚 | カードをクリック / 1〜5 | カードをタップ |
| 速度（×1・×2・×3） | 右上のボタン / F | 右上のボタン |
| 一時停止 | 右上のボタン / Esc | 右上のボタン |
| 音 | 右上のボタン / M | 右上のボタン |

## ローカルで動かす

ビルドは不要です。このフォルダをそのまま静的サーバーで開きます。

```sh
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

`index.html` を直接開いても遊べますが、ブラウザによっては保存が効かないことがあるため、サーバー経由をおすすめします。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | 画面の骨組み・HUD・メニューのスタイル |
| `game.js` | 戦闘（ユニット・敵・ボス・ウェーブ・祝福）と数値の設定 |
| `art.js` | すべてのグラフィック（Canvas 2D のコードで描画） |
| `abilities.js` | 能力ガチャ・交換所・夢の結晶・セーブ |
| `menu.js` | タイトル・ガチャ・編成・交換所・記録の画面 |
| `audio.js` | 効果音と音楽（Web Audio で生成） |

数値はすべて試験中の仮の値です。
